# Synthetic Demo Data

These CSVs are **synthetic/demo data**, generated by a script for development
and demo purposes. They must never be auto-loaded into a real user's account.

- `sample_retail_business.csv` — 24 months, small retail shop
- `sample_restaurant_business.csv` — 24 months, restaurant
- `sample_online_store.csv` — 24 months, online store

To use one for a demo: register a business in the app, mark it as
"I'm already running a business", then upload the CSV via
**Business Data → Upload CSV**. The UI should label any business populated
this way as using "Synthetic Demo Data" until real data replaces it.
